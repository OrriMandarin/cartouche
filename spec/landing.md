# Landing page

> Statut : spécifié, non implémenté (plan 6) ; LND-004 et LND-005 : plan 5

- **LND-001** — La landing page est une page publique de présentation du produit.
- **LND-002** — La landing page contient un appel à l'inscription.
- **LND-003** — La landing page contient un lien vers le dépôt GitHub du projet.
- **LND-004** — Les pages CGU et confidentialité sont deux pages statiques dont le contenu est fourni par l'opérateur de l'instance (fichiers Markdown dans la configuration), avec un modèle par défaut.
- **LND-005** — Les pages CGU et confidentialité sont liées depuis la landing page et depuis l'inscription.
